## Как менять сведения

Открой `event-config.js` и измени значения в кавычках. Там находятся дата, время, адрес, цена, WhatsApp, ссылка 2GIS и описание исполнителя. WhatsApp можно включить после получения номера организатора.

## Публикация и нагрузка

Сайт — статическая страница на GitHub Pages. Он не зависит от включённого ноутбука: GitHub отдаёт опубликованные файлы со своей стороны. На телефоне дата, время, адрес, цена и ссылка на 2GIS доступны в компактной раскладке; горы двигаются плавно и без JavaScript.

Два изображения вместе занимают около 1,6 MB; 300 полных загрузок страницы передали бы примерно 0,5 GB, не считая небольших HTML/CSS/JS-файлов и сетевых накладных расходов. GitHub указывает мягкий лимит пропускной способности Pages 100 GB в месяц; возможны защитные ограничения запросов, поэтому это не гарантия для любого всплеска.

После изменения файлов отправь commit в `main`; GitHub Pages автоматически обновит сайт. При доступности GitHub и включённой публикации ссылка останется открытой и 20 ноября.

Фотографии и афиша взяты из изображений, присланных организатором. Биография и состав TWO’US не добавлены без подтверждённых источников. Адрес и расписание внесены по сообщению организатора; точный зал или корпус можно уточнить отдельно.
