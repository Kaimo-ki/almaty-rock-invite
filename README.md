# TWO’US × ATU Music Club — концерт в Алматы

Две версии страницы GitHub Pages:

- С благодарностью ATU: https://kaimo-ki.github.io/almaty-rock-invite/
- Без благодарности: https://kaimo-ki.github.io/almaty-rock-invite/without-thanks.html

## Данные концерта

- Дата: 20 ноября 2026 года
- Начало: 18:00
- Адрес: Алматы, ул. Толе би, 100
- Площадка: Үлкен мәжіліс залы (Большой зал заседаний)
- Вход: свободный
- Участники: TWO’US, ATU Music Club
- Хедлайнер: MEREY

Организатор сообщил, что TWO’US образовалась в 2023 году. Обе страницы доступны на русском и казахском; язык переключается в шапке. Адрес открывается в 2GIS с центром на кампусе ATU.

## Как менять сведения

- event-config.js — дата, время, адрес, площадка, цена и ссылки 2GIS на карту и маршрут.
- main.js — русские и казахские тексты и переключатель языка.
- index.html — разметка страницы, соцсети, ссылки на песни и фото.
- styles.css — оформление и адаптивная раскладка.
