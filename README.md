# JAŃA TOLQYN — концертное приглашение

Локальный черновик. В GitHub он пока не загружен.

## Что уже есть

- афиша и групповая фотография, которые прислала Молли;
- анимированное солнце, горы, город и сценические прожекторы;
- промо-блок TWO’US сбоку на широком экране;
- цена из брифа — **2 000 ₸**;
- карточки даты, площадки, 2GIS и WhatsApp, готовые к заполнению.

## Как посмотреть

Открой `index.html` в браузере. Внешние шрифты подгружаются из Google Fonts; если они недоступны, останутся системные шрифты.

## Как менять данные вечера

Открой `event-config.js` и замени значения в кавычках:

- `dateLabel`, `timeLabel` — дата и время;
- `venueLabel` — короткая подпись площадки;
- `price` — цена;
- `whatsappNumber` — номер WhatsApp с кодом страны, только цифры;
- `twoGisUrl` — полная ссылка на точку в 2GIS;
- `artistDescription` — подтверждённое описание TWO’US.

Пустые `whatsappNumber` и `twoGisUrl` специально оставлены незаполненными: соответствующие кнопки покажут подсказку, пока организатор не добавит контакты.

## Проверка фактов

На предоставленной афише читаются `JAŃA TOLQYN`, `ROCK CONCERT` и `TWO’US`. По открытому поиску не удалось надёжно сопоставить TWO’US с официальным профилем именно этих музыкантов, поэтому биография, состав, ссылки, дата и площадка не придуманы. В сети название `Jaña Tolqyn` встречается и в других, не связанных с этой афишей контекстах, поэтому такие результаты здесь не использованы.

## Публикация после согласования

В папке уже есть workflow для GitHub Pages. После утверждения можно загрузить содержимое этой папки в новый репозиторий; платежей на сайте нет — кнопка WhatsApp предназначена для связи с организатором и обсуждения оплаты.
