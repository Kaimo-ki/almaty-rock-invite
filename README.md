## Как менять сведения

Открой `event-config.js` и измени значения в кавычках. Там находятся дата, время, адрес, цена, WhatsApp, ссылка 2GIS и описание исполнителя. WhatsApp можно включить после получения номера организатора.

## Публикация и нагрузка

Это статическая страница без базы данных и платёжных запросов. Два изображения вместе занимают около 1,6 MB; 300 полных загрузок страницы передали бы примерно 0,5 GB, не считая небольших HTML/CSS/JS-файлов и сетевых накладных расходов. GitHub указывает мягкий лимит пропускной способности Pages 100 GB в месяц; возможны защитные ограничения запросов, поэтому это не гарантия для любого всплеска.

После изменения файлов отправь commit в `main`; GitHub Pages обновит сайт.

## Материалы и факты
